**iShareBudget** — приложение для совместного ведения бюджета на iOS. Создавайте бюджеты для семьи, поездки или общего проекта, делитесь ими с близкими через iCloud и следите за доходами и расходами вместе — в реальном времени.

## Возможности

- 💰 **Несколько бюджетов** — отдельные бюджеты со своей валютой (₽, $, €, ₸), каждый со своим набором категорий
- 👨‍👩‍👧 **Совместный доступ через CloudKit** — делитесь бюджетом с семьёй одной ссылкой, изменения участников появляются у всех почти мгновенно
- 🔐 **Разграничение прав** — владелец управляет бюджетом и категориями, участники добавляют операции и могут удалять только свои
- 🧾 **Распознавание чеков с помощью ИИ** — сфотографируйте чек или скриншот оплаты, и приложение само заполнит сумму, категорию, дату и способ оплаты; поддерживаются OpenAI и локальные модели (LM Studio, Ollama и другие OpenAI-совместимые серверы)
- 📤 **Импорт через Share Extension** — отправьте фото чека прямо из Фото или другого приложения в iShareBudget
- 🏷️ **Гибкие категории** — свои иконки, цвета и типы (доход / расход / универсальная)
- 📊 **Аналитика** — разбивка расходов по категориям и сводка за месяц
- 📁 **Экспорт в CSV** — выгрузка всех операций для внешнего анализа
- 🌍 **Локализация** — интерфейс на нескольких языках
- 🚀 **Онбординг** — короткое знакомство с приложением при первом запуске
- 🔔 **Уведомления** — напоминания и синхронизация через CloudKit push-подписки

## Технологии

SwiftUI · SwiftData · CloudKit (CKShare) · Swift Testing

## Основано на

Слой совместного доступа к бюджетам через CloudKit — создание `CKShare`, кастомная зона синхронизации, приём приглашений через `SceneDelegate`, модель прав «владелец / участник» и трёхуровневая синхронизация в реальном времени (polling-таймер + push-уведомления + мост `NSPersistentStoreRemoteChange`) — взят и адаптирован из открытого проекта-шаблона [**CloudKit Sharing + SwiftData**](https://github.com/framara/CloudKitSharing) от [framara](https://framara.net). Большое спасибо за отличный референс — без него реализация шаринга заняла бы в разы больше времени.

Всё остальное — модели данных (бюджеты, категории, операции), ИИ-распознавание чеков, экспорт в CSV, онбординг, локализация и весь UI — написано специально для iShareBudget.
